## Decision

Implement an explicit developer workspace <path> control as one owned workspace-replacement operation in the existing runtime ledger. It is a session operation, not a shell cd, plugin instruction or automatic model correction. Validate and capture the canonical destination, its descriptor/device/inode identity, current root generation, connection, policy and original session owner before any effect. The explicit control authorizes only that selected directory; a startup trust flag does not authorize future paths. Preserve credential exclusions, host/strict access semantics and final-request Oracle rules. Reject unavailable or unsafe targets without changing the old session.

For this bounded prerequisite, require an idle reconciled session with no unaccepted task and no unresolved child assignments or active child jobs. Retain accepted task history through existing archival rules; do not reinterpret its snapshots, verification or worktrees as evidence for the new root. Refuse active, queued, interrupted, uncertain or unreconciled work rather than migrating or silently cancelling it. A repeated request for the same admitted directory is a no-op with no transition event or renewed authority.

Prepare replacement root-bound tools and a controlled provider without running a model or loading destination packages. Rebind the host workflow, runtime current root, Manager admission root, Settings capability and terminal display coherently. Keep child admission paused through the transition and capture one immutable root per later job. Reuse existing Manager ownership when possible; preparation must not reconfigure active runtime state. Revoke and drain old Settings attempts, observers and services before the new root becomes usable. Serialize final old-root validation, Settings publication and root publication using the existing lock order. Both an old captured Settings handle and a gate not yet recorded in the ledger must remain stale, including after A-to-B-to-A. Future model selection must resolve against the admitted current workspace instead of startup Args.workspace.

Retain the original session lifetime, exact allowance object, counters, deadline, service capacity and once state. A workspace selection grants file authority only after validation, never new execution funding. Store an exact ordered from/to root transition and predecessor in the existing operation ledger, not a second root or budget database. Current-root validation follows only applied transitions of that original live lifetime, preserving the independent exact model identity chain. Never relax generic lifetime validation to accept any workspace. Retain the original native SessionEnd owner, root descriptor/path identity and startup policy; replacing or renaming that original root makes the observation unavailable, never redirects it to a different directory, and never prevents bounded cleanup.

Persist preparation and teardown before their effects. Revalidate cancellation, recovery, captured root identity and original authority at final release. Stop owned old execution and close the old provider before publishing the replacement; durable publication and live installation have no intervening await. A pre-effect refusal leaves the old root usable. Teardown or persistence uncertainty holds further work and retains its actual stage. After application, record the applied result before observers; their failure cannot report that the workspace reverted. Restart retains uncertainty and completed receipts without replaying transitions or reviving original live authority.

Preserve CODE-006 relevant conversation continuity. Reuse the existing native checkpoint path where sound. For an external backend, use a bounded truthful handoff of retained preceding conversation and evidence into the next explicitly submitted turn; preserve roles/provenance and old-root attribution, exclude old executable plugin instructions, and do not invent opaque backend restore or run a hidden summarizing/model turn. If the retained history cannot establish the required continuity within existing bounds, hold the transition instead of silently dropping it. Prove actual next-provider input and next-root tool effects, not just retained UI text.

Dispatch CwdChanged only after the actual admitted host replacement. No PreWorkspaceChange event exists and CwdChanged is not a veto. PCOMP-003 assigns this operation to the same host owner on all four connections. Native handlers use all five existing runners; supported Claude command/HTTP/MCP declarations may consume truthful host old/new facts in the agreed wire format, with host provenance and existing source-specific result semantics. This is not a claim that Claude emitted an SDK callback. Codex has no source CwdChanged event; preserve explicit native selection. Suppress only a genuinely correlated duplicate, never synthesize source observations. Do not use the pinned live set_cwd control: it rehomes backend configuration, skills, memory and plugins, and this behavior is not qualified for immutable host activation. Controlled backend replacement preserves isolation.

Dynamic watch replacement and DirectoryAdded remain separate required work in this same commitment. This prerequisite does not claim full CwdChanged output conformance: unsupported watch effects must remain visibly unapplied and must not receive a false success receipt. Do not add an unreviewed multi-root access model, activate destination packages, migrate tasks, erase old receipts or reduce the complete profile. Implement the subsequent watch registry before marking the combined lifecycle obligation complete.

Demonstrate actual native OpenAI/Anthropic and installed Claude/Codex root replacement with distinct A/B file canaries and relevant conversation carried to the next explicit prompt. Exercise invalid/untrusted or changed targets, no-op, active tasks/children, stale captured Settings including A-to-B-to-A, cancellation/shutdown, close/persistence failures, restart/no replay, original counters/deadline, model switch after workspace switch and original SessionEnd root replacement. Exercise applicable real runners and observer failure without rollback. Retain exact commands, source candidates and raw results, including violating controls. Finish focused checks and independent specification review before the full regression alongside independent quality review. This is a bounded prerequisite, not completion of lifecycle dispatch or the 41-requirement commitment.
